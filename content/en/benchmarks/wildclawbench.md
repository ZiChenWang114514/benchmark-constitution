# WildClawBench

A real-world long-horizon agent benchmark of 60 human-authored bilingual tasks run in isolated containers across shell, browser, file system and email, with hybrid verification. The official OpenClaw leaderboard is topped by GPT-5.6 Sol at 67.2%, and its multimodal variant appears in the official Qwen3.8-Omni-Flash release.

## Design goals

**Capabilities tested**：Evaluates agents in native runtimes on long-horizon cross-application workflows over shell, browser, file system and email, including multi-round exchanges with mocked participants, verifying information under ambiguity and search budgets, and catching prompt injections, leaked credentials and dangerous commands.

Sources: [1](https://arxiv.org/abs/2605.10912) [2](https://github.com/InternLM/WildClawBench) [3](https://huggingface.co/datasets/internlm/WildClawBench) [4](https://www.alibabacloud.com/blog/qwen3-8-omni-flash-omni-senses--agentic-delivery-_603580) (accessed 2026-11-16)

**Gap in prior benchmarks**：The paper notes that prior benchmarks support only a subset of cross-modal inputs, auditable trajectories, native runtimes, bilingual coverage, reproducible containers and hybrid verification, while WildClawBench combines them.

Sources: [1](https://arxiv.org/abs/2605.10912) [2](https://github.com/InternLM/WildClawBench) [3](https://huggingface.co/datasets/internlm/WildClawBench) [4](https://www.alibabacloud.com/blog/qwen3-8-omni-flash-omni-senses--agentic-delivery-_603580) (accessed 2026-11-16)

## Construction

**Question sources**：All tasks are human-authored; a team of 8 researchers spent two weeks on task authoring, reference answers, filtering and iterative refinement.

Sources: [1](https://arxiv.org/abs/2605.10912) [2](https://github.com/InternLM/WildClawBench) [3](https://huggingface.co/datasets/internlm/WildClawBench) [4](https://www.alibabacloud.com/blog/qwen3-8-omni-flash-omni-senses--agentic-delivery-_603580) (accessed 2026-11-16)

**Author background**：Unverified

Sources: [1](https://arxiv.org/abs/2605.10912) [2](https://github.com/InternLM/WildClawBench) [3](https://huggingface.co/datasets/internlm/WildClawBench) [4](https://www.alibabacloud.com/blog/qwen3-8-omni-flash-omni-senses--agentic-delivery-_603580) (accessed 2026-11-16)

**Review process**：A four-stage pipeline; experts write a reference answer or verifiable grading points for VLM or LLM judges before model evaluation, then filter tasks by reviewing prompts, references, grading outputs, transcripts, runtime logs and failures, redesigning tasks whose difficulty came from ambiguity, brittle grading, hidden leakage or unreproducible environments.

Sources: [1](https://arxiv.org/abs/2605.10912) [2](https://github.com/InternLM/WildClawBench) [3](https://huggingface.co/datasets/internlm/WildClawBench) [4](https://www.alibabacloud.com/blog/qwen3-8-omni-flash-omni-senses--agentic-delivery-_603580) (accessed 2026-11-16)

**Quality control**：Unverified

Sources: [1](https://arxiv.org/abs/2605.10912) [2](https://github.com/InternLM/WildClawBench) [3](https://huggingface.co/datasets/internlm/WildClawBench) [4](https://www.alibabacloud.com/blog/qwen3-8-omni-flash-omni-senses--agentic-delivery-_603580) (accessed 2026-11-16)

**Decontamination**：Each task runs in an isolated Docker container; ground truth and grading resources are mounted only after the agent exits, preventing leakage during execution.

Sources: [1](https://arxiv.org/abs/2605.10912) [2](https://github.com/InternLM/WildClawBench) [3](https://huggingface.co/datasets/internlm/WildClawBench) [4](https://www.alibabacloud.com/blog/qwen3-8-omni-flash-omni-senses--agentic-delivery-_603580) (accessed 2026-11-16)

## Evaluation

**Metrics**：Overall score (weighted multimodal and text-only); time and cost per task are also reported

Sources: [1](https://arxiv.org/abs/2605.10912) [2](https://github.com/InternLM/WildClawBench) [3](https://huggingface.co/datasets/internlm/WildClawBench) [4](https://www.alibabacloud.com/blog/qwen3-8-omni-flash-omni-senses--agentic-delivery-_603580) (accessed 2026-11-16)

**Scoring**：Hybrid verification: rule matching, executable checks, state checks via environment, script or screenshot, and multi-signal integration; all models go through a unified endpoint with tool schemas and system prompts fixed within each harness.
