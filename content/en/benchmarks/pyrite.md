# Pyrite

A pairwise protein-ligand pose-ranking benchmark of 1,500 cofolded pose pairs over 285 structures. The paper reports expert chemists near chance, while PyriteFeaturizer, combining code features with LLM subcalls, reaches up to 74% accuracy.

## Design goals

**Capabilities tested**：Given two predicted binding poses for the same protein-ligand complex, decide which is closer to the crystallographic binding mode; tests whether language-model agents reasoning over the same computational tool outputs as chemists can rank more accurately than the tools or the experts.

Sources: [1](https://arxiv.org/abs/2611.14511) [2](https://arxiv.org/pdf/2611.14511) [3](https://github.com/genesistherapeutics/pyrite) [4](https://huggingface.co/datasets/genesisml/pyrite) (accessed 2026-11-16)

**Gap in prior benchmarks**：The paper notes that earlier work pairing LLM agents with physicochemical tools to rank classical docking poses only matched, rather than exceeded, the underlying scoring function on a small benchmark, and that cofolding models now produce many plausible binding modes that lack a challenging ranking benchmark.

Sources: [1](https://arxiv.org/abs/2611.14511) [2](https://arxiv.org/pdf/2611.14511) [3](https://github.com/genesistherapeutics/pyrite) [4](https://huggingface.co/datasets/genesisml/pyrite) (accessed 2026-11-16)

## Construction

**Question sources**：The authors' proprietary cofolding model with diversity-promoting sampling generates up to 120 poses per query for more than 50,000 RCSB PDB structures; poses are categorized by RMSD to the crystal and lDDT-PLI, then filtered into pairs.

Sources: [1](https://arxiv.org/abs/2611.14511) [2](https://arxiv.org/pdf/2611.14511) [3](https://github.com/genesistherapeutics/pyrite) [4](https://huggingface.co/datasets/genesisml/pyrite) (accessed 2026-11-16)

**Author background**：Expert annotations come from chemists using an interface with a 2D contact map, interactive 3D views, MM-GBSA scores and Mogul unusual-torsion counts.

Sources: [1](https://arxiv.org/abs/2611.14511) [2](https://arxiv.org/pdf/2611.14511) [3](https://github.com/genesistherapeutics/pyrite) [4](https://huggingface.co/datasets/genesisml/pyrite) (accessed 2026-11-16)

**Review process**：Experts select which pose is closer to the crystal binding mode on a 1 to 5 scale, list factors favouring each pose and explain how they weighed them.

Sources: [1](https://arxiv.org/abs/2611.14511) [2](https://arxiv.org/pdf/2611.14511) [3](https://github.com/genesistherapeutics/pyrite) [4](https://huggingface.co/datasets/genesisml/pyrite) (accessed 2026-11-16)

**Results snapshot**：Author-run. PyriteReasoner, which ranks pairs by text-based chemical reasoning, reaches up to 67%; PyriteFeaturizer, combining code-derived descriptors with LLM-generated features, reaches up to 74%, the best on the benchmark. On post-AF3 curated, plain logistic regression scores 64% mean per-pose accuracy, above Sonnet 5 and GPT-5.6-sol but below the strongest LLM, Opus 4.8. GRPO training lets open-weight models match or surpass closed frontier models.
