# BioXArena-Pro

An end-to-end biomedical modelling benchmark for agents: 64 research-grade tasks across eight domains, one GPU and two hours per task, with private test labels. The paper reports Codex CLI with GPT-6 Astra as the best of 22 configurations at 55.1 of 100.

## Design goals

**Capabilities tested**：Agents get one GPU and a two-hour budget to build a model end to end from training data and unlabelled test inputs and submit predictions, testing whether held-out performance on research-grade biomedical data reflects real modelling ability.

Sources: [1](https://arxiv.org/abs/2611.13994) [2](https://arxiv.org/pdf/2611.13994) [3](https://github.com/mbzuai-ai4bio/BioXArena-Pro) [4](https://huggingface.co/datasets/mbzuai-ai4bio/BioXArena-Pro-Public) (accessed 2026-11-16)

**Gap in prior benchmarks**：The paper notes that most scientific and biomedical agent benchmarks test knowledge, tool use or analysis traces rather than end-to-end model building, and existing model-building benchmarks are small, competition-derived or limited to clean tabular data and random splits. The team's earlier BioXArena (76 tasks, 9 domains) is near saturation, with the two strongest configurations averaging 66.

Sources: [1](https://arxiv.org/abs/2611.13994) [2](https://arxiv.org/pdf/2611.13994) [3](https://github.com/mbzuai-ai4bio/BioXArena-Pro) [4](https://huggingface.co/datasets/mbzuai-ai4bio/BioXArena-Pro-Public) (accessed 2026-11-16)

## Construction

**Question sources**：Each task reproduces a research-grade modelling problem from a published study or database, keeping the original distribution shift, data volume and native formats; each has a reproduced published-method reference (33 methods published for the dataset, 31 strongest methods for the problem class).

Sources: [1](https://arxiv.org/abs/2611.13994) [2](https://arxiv.org/pdf/2611.13994) [3](https://github.com/mbzuai-ai4bio/BioXArena-Pro) [4](https://huggingface.co/datasets/mbzuai-ai4bio/BioXArena-Pro-Public) (accessed 2026-11-16)

**Review process**：Unverified

Sources: [1](https://arxiv.org/abs/2611.13994) [2](https://arxiv.org/pdf/2611.13994) [3](https://github.com/mbzuai-ai4bio/BioXArena-Pro) [4](https://huggingface.co/datasets/mbzuai-ai4bio/BioXArena-Pro-Public) (accessed 2026-11-16)

**Quality control**：The release includes the audit protocol, reproduced references and all agent traces; scores are mapped to a common 0 to 100 scale, higher is better.

Sources: [1](https://arxiv.org/abs/2611.13994) [2](https://arxiv.org/pdf/2611.13994) [3](https://github.com/mbzuai-ai4bio/BioXArena-Pro) [4](https://huggingface.co/datasets/mbzuai-ai4bio/BioXArena-Pro-Public) (accessed 2026-11-16)

**Decontamination**：Test labels and answer files are private to prevent contamination, and test scores come from submitting predictions to a Codabench competition; some tasks were rebuilt against contamination (new split, removed inputs or new metric), and ten descriptions withhold the source name to limit lookup.

Sources: [1](https://arxiv.org/abs/2611.13994) [2](https://arxiv.org/pdf/2611.13994) [3](https://github.com/mbzuai-ai4bio/BioXArena-Pro) [4](https://huggingface.co/datasets/mbzuai-ai4bio/BioXArena-Pro-Public) (accessed 2026-11-16)

## Evaluation

**Metrics**：Metrics follow the scientific output, 75% averaged per group, all mapped to 0 to 100; the 64-task mean is reported with 95% bootstrap confidence intervals
